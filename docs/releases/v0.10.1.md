# AuraScan v0.10.1

Released on 2026-08-31.

## Actionable Instruction Guard Reviews

- Terminal reviews now separate suspicious instructions, incomplete scan or
  discovery coverage, and new or changed files awaiting integrity approval. A
  clean first-seen file is described as lacking a machine-bound approval, not
  as a LOW malware finding.
- Each located content correlation shows exact one-based contributing line
  ranges and the behavior role observed at each range, followed by a fixed
  deterministic explanation of why the roles matter together. Source text and
  snippets are not printed or persisted as evidence.
- Bounded AI explanations are mapped to deterministic evidence and labeled
  advisory. The summary reports how many eligible findings received an AI
  explanation; AI cannot create or move a line, lower deterministic severity,
  establish trust, or replace the fixed reason.
- Changed and safely readable standalone files now receive a concrete next
  step. `-A FILE_ID` is the compact alias for
  `--approve FILE_ID`; unsafe or symlinked states remain manual-only.
- Malformed configuration is presented as incomplete scan coverage rather
  than as suspicious content. Saved discovery continuation remains visible as
  a coverage limitation until the bounded scan completes.

## Evidence Precision And Compatibility

- Physical source locations remain exact across bounded multiline and shell
  continuation analysis, while each range receives only the behavior role
  actually supported there. Legacy reports without precise locations say so
  explicitly and can be refreshed by scanning again.
- Terminal output is grouped and wrapped within a bounded 60-to-120-column
  width without splitting IDs. Schema-compatible JSON bypasses presentation
  wrapping. Review output stays secret-free: it does not include source
  snippets, credentials, URLs from scanned text, rejected model output, or
  desktop-notification details.
- Instruction Guard report schema and rule version remain `1.0`, and the
  stable AI evidence alias remains `1.1`. Internal analysis evidence version
  advances to `1.2`, causing a conservative one-time reanalysis so cached files
  receive the improved line-role evidence without changing approval semantics.
- The package scanner remains scanner version `2.5.0` and rule version `1.4.0`.
  This release changes Instruction Guard evidence precision and presentation;
  it does not add a package-rule or report-schema migration.

## Testing And Packaging

- Added inventory-only, suspicious-only, mixed, changed, coverage-limited,
  continuation, legacy-report, narrow-terminal, maximum-field, and adversarial
  output tests. CLI tests verify terminal-width forwarding and prove that JSON
  review bypasses terminal rendering.
- The application and Arch/AUR package advance to v0.10.1. CI keeps both AI
  modes disabled and does not scan the developer's real home, contact a
  provider, start a model, run live systemd, execute fixture commands, or
  require root.
