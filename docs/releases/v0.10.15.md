## Pacman-hook progress feedback

The hook now announces that it is working instead of leaving the pacman
transaction apparently stuck. It prints:

- a flushed start line with the number of package archives to audit;
- the current archive for a small transaction, or the first archive for a
  large update;
- an ASCII progress bar at most every two seconds, with completed and total
  counts, percentage, and elapsed seconds;
- a clear `Full scan` line before a local or AUR archive that needs the longer
  scan path.

The output stays line-based and ASCII because pacman captures hook output
through a pipe. Progress lines are explicitly flushed, so they appear while
the audit is running instead of arriving only at process exit.
