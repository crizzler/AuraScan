## Hung-application diagnosis

`aurascan doctor` now inspects the bounded `/proc` process tree for a
wait-then-read pipe deadlock. The signature is deliberately narrow: a parent
sleeping in a wait syscall while its `lsmod` child is blocked in
`anon_pipe_write`. This distinguishes a started-but-hung application, such as
Goverlay 1.9.4 during OptiScaler tab construction, from a missing shared
library. The check reads process metadata and never signals, attaches to, or
executes the inspected application.

When a cached older package archive exists, use:

```bash
aurascan doctor --fix-hung-apps
```

AuraScan prints the blocked parent/child and package version, offers the
newest cached older build, and runs `pacman -U` through the trusted sudo/pacman
handoff only after confirmation. It does not modify `pacman.conf`; if no cached
downgrade is available it recommends IgnorePkg or waiting for the fixed build.
The hung instance must be closed and restarted after a downgrade.
