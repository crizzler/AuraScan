# AuraScan v0.10.5

Released on 2026-09-09.

AuraScan v0.10.5 is a recovery-bearing release because the Git source-acquisition
security boundary is shared with recovery.

## CodeWhale and DeepSeek trust boundaries

- Agent Instruction Guard discovers repository-local CodeWhale and legacy
  DeepSeek TOML config files. Clean files remain neutral baseline work.
  Credential-bearing user-global configs are excluded from project detection
  and reads. Supported top-level shell enablement requires HIGH review;
  malformed or unsupported TOML reports incomplete coverage. Settings are never
  executed, and a static match does not establish an affected installed version.
- Instruction references are checked against their containing project,
  including recursive and continued work. Escapes and credential-file targets
  are refused without reads; symlinks and ambiguous parent traversal remain
  manual-only. Findings preserve bounded line roles without source snippets.
  Continued discovery and cached analysis retain the project boundary without
  treating stale context as current authorization.
- Security audit checks captured CodeWhale/legacy package versions against nine
  verified upstream advisories. Unknown versions, ecosystem ambiguity and
  unverified backports remain explicit; exposure does not imply exploitation
  or a currently vulnerable AUR publication. Custom aliases and installations
  outside the captured package database are outside this version check.
- Source acquisition rejects option-shaped Git branch/tag fragments before Git
  runs. Inert runner-spy regressions cover decoded options and normal refs;
  package payloads and fixture commands are never executed by these tests.
- Updates `AGENTS.md`, `SKILL.md`, user and contributor documentation for the
  project/global configuration distinction and bounded TOML/import handling.

## Recovery distribution and boundaries

This recovery-bearing release publishes a fresh optional hybrid BIOS/UEFI
image as one indivisible set: `aurascan-recovery-0.10.5-x86_64.iso`, its
`.iso.sha256` sidecar, and sorted `.iso.packages.txt` manifest. The builder
rejects a GitHub release asset at or above 2 GiB. It requires fresh work and
output locations in a disposable Arch VM with externally bounded CPU, RAM,
and disk and no host disk or home shares.

Recovery remains optional. Locally built UKIs remain specific to the builder
kernel and disposable test keys; they are not universal download assets.
Every future release declares either `recovery-bearing` or `package-only`.
No previous release or tag is rewritten. A digest binds exact bytes, not
package safety, successful recovery, or the absence of every possible secret.
