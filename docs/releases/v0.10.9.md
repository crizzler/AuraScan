# AuraScan v0.10.9

Released on 2026-09-12.

AuraScan v0.10.9 is a package-only release. It adds bounded Cursor control
review to Agent Instruction Guard and inert regressions for scanner-directed
instructions and provenance claims. Recovery runtime, recipes, dependencies,
boot tooling, package analyzers, provider handling and shared security
boundaries are unchanged. The added rule metadata and presenter entries serve
only Instruction Guard findings.

## Cursor control review

- Discovers `.cursor/rules/**/*.mdc`, legacy `.cursorrules`,
  `.cursor/mcp.json` and `.cursor/permissions.json` through bounded no-follow
  reads, stable snapshots and paged discovery. Clean files remain neutral
  baseline-enrollment work; changed or unsafe files require review. Cursor
  controls remain manual-only for disable/restore.
- Parses supported JSON/JSONC configuration structurally. The HIGH
  `IG-CONFIG-CURSOR-BROAD-GRANT` finding requests review of broad approval
  authority, including wildcard MCP grants; a grant alone does not establish
  maliciousness or execution. The HIGH
  `IG-CONFIG-CURSOR-COMMAND-BEHAVIOR` finding correlates retrieval with execution
  or credential-file access with outbound transfer within the same supported
  server command. `IG-CONFIG-CURSOR-AUTOREVIEW-BEHAVIOR` retains HIGH review of
  correlated sensitive instructions in supported Auto-review allow guidance.
- Keeps ordinary tools, authentication placeholders, metadata, quoted command
  arguments and JSON comments separate from active command evidence. JSON
  comments cannot authorize Markdown imports, including through cached
  analysis. Malformed, ambiguous, oversized or unsupported active configuration
  remains incomplete inspection rather than being labeled malware.
- Never launches Cursor or an MCP server, expands variables, reads referenced
  credential files, resolves endpoints or executes configured commands.
  Findings describe captured local configuration; they cannot establish
  Cursor's effective merged user/team policy, tool approval, activation,
  campaign attribution or compromise. Plugin component traversal, CLI
  permissions and arbitrary MCP implementation analysis remain deferred.

The [GTIG DUSTMAKER report](https://cloud.google.com/blog/topics/threat-intelligence/from-prompting-to-autonomy-the-evolution-of-adversarial-ai)
motivated this review. It provides no exact affected package range suitable
for a new AuraScan denylist. Coverage follows the supported portions of
[Cursor rules](https://prod.cursor.com/docs/rules),
[MCP configuration](https://prod.cursor.com/docs/mcp) and
[permissions](https://prod.cursor.com/docs/reference/permissions).

## Existing package-AI boundaries

Inert regressions verify that optional AI refusal, malformed output or claimed
attested provenance cannot erase deterministic package blockers. Tests use
temporary roots, fake credentials, `example.invalid` and mocked providers;
they execute no sample payload, fixture command or package code. AuraScan does
not implement SLSA attestation verification. A package's attestation claim
cannot establish trust, and verified source metadata cannot waive static
findings. Package AI can receive bounded numbered package text, including
comments; Instruction Guard AI receives fixed evidence without file contents.
No provider behavior or package-analysis implementation changes in this release.

Application and Arch/AUR package advance to v0.10.9. Instruction analysis
evidence advances to `1.4` to invalidate older cached analysis. Instruction
Guard report schema and rule version remain `1.0`; package scanner version
remains `2.5.0` and package-scanner rule version remains `1.9.0`. Runtime stays
Python 3.8+ with standard-library-only dependencies. AI stays separately opt-in
and advisory; deterministic policy remains authoritative.

## Release validation

Publication requires the complete source suite, compilation, presenter audits,
shell/unit and package-metadata checks, a clean Arch package build, the exact-ref
Python 3.8/3.14 CI matrix, and re-verification of the retained image's public
identity and digest. Recovery boot and live-scenario gates are not rerun for
this package-only release.
