## A read-only MCP server exposes the detection layer to an agent

`aurascan-mcp` is a stdlib-only JSON-RPC 2.0 stdio server with four tools:
`scan_content`, `scan_path`, `audit_agent_config`, and `security_audit`. The
first two port the reverse-AntiCopy prompt-injection detector: a static,
rule-based first signal for text that looks like instructions aimed at an AI
reader. The detector never executes, fetches, writes, or blocks anything.

`audit_agent_config` audits an agent/MCP configuration document as inert text,
including `mcpServers` command behaviour. `security_audit` runs the existing
host audit in pinned offline mode: no network, no state writes, one bounded
`pacman -Q` read, and no removal or quarantine action.

All four tools carry `readOnlyHint: true`, `destructiveHint: false`, and
`openWorldHint: false`. The server is intended for registration with
`trust: untrusted` and a narrow per-tool allowlist; the four tools are not
containment, and a finding is evidence rather than proof of compromise.
