# AuraScan 0.17.0

Release date: 2026-11-11.

This is a recovery-bearing release candidate. The recovery image and local UKI
must be rebuilt and gated before publication; the recovery manifest remains
`build-required` until those gates pass.

## Changes

- Recovery image validation now fails closed when `ukify` is unavailable,
  instead of accepting a weaker byte and PE check. A release that changes this
  path is recovery-bearing and requires fresh ISO and UKI evidence.

Publication remains blocked until the 0.17.0 ISO and UKI gates are recorded.
