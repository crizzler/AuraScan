# AuraScan 0.19.0

Released on 2026-11-14.

AuraScan 0.19.0 is a package-only release. It adds Agent Guard, a read-only
blast-radius preflight for external coding agents, without adding a model
scanner or a claim that a model is safe. The retained recovery image is
`aurascan-recovery-0.10.11-x86_64.iso`; the ISO and local-UKI gates were not
rerun for v0.19.0.

## Agent Guard

- New `aurascan agent-audit --root PATH --surface codex|claude|cursor|mcp`
  reports execution authority, readable project secret classes, host-isolation
  uncertainty, coverage and an evidence digest.
- Codex, Claude Code and Cursor include their built-in shell authority. Hook
  commands and MCP stdio commands are reported as explicit channels.
- A missing, unreadable, symlinked, FIFO-like, malformed or unsupported selected
  file is incomplete coverage and exits `3`; it is never a clean result.
- Exit `0` means every selected file parsed and no execution authority was
  observed. Exit `1` means execution authority was observed with complete
  coverage. Exit `2` is usage; exit `4` is an internal schema failure.
- Secret values and secret paths are never emitted. The project-scope inventory
  reports class names and counts only; home, environment, keyring and socket
  credentials are explicitly out of scope.
- `audit_agent_runtime` exposes the same preflight through the read-only MCP
  server using its first configured root, with aggregate output only and no
  paths.
- The desktop console adds an **Agent runtime** view. The directory comes from a
  native dialog, the surface from a fixed list, and the renderer receives only
  aggregate facts. There is no "Harden this setup" action.

The report is not a model-safety verdict. A backdoored model can pass every
configuration check; the report describes blast radius, not model intent.

## Compatibility and limits

- Python 3.8 through 3.14 source support is retained.
- The reviewable launch path remains the CLI; the MCP and desktop projections
  are read-only views over the same deterministic core.
- The hardened launcher from the Agent Guard design remains unfunded and is not
  part of this release.
- The retained recovery image remains the v0.10.11 image. No new ISO, UKI,
  Secure Boot or booted-target-disk claim is made for 0.19.0.
