# AuraScan v0.7.1

Released on 2026-07-27.

## Security Audit

- Added `aurascan security-audit` with a validated, provenance-labeled snapshot
  of the June 2026 AUR campaign package list, bounded HTTPS refresh, installed
  package and pacman-history correlation, and private cache permissions.
- Added optional `arch-audit --json` integration while keeping official
  repository CVE advisories distinct from AUR campaign exposure.
- Added known campaign checks to upgrade preflight and CRITICAL pre-build/deep
  static rules for `atomic-lockfile`, `lockfile-js`, and `js-digest`.
- Security-intelligence matches never trigger automatic package removal and no
  result is presented as proof that a host is clean.

## Packaging

- Added `arch-audit` as an optional Arch package dependency.
- Updated the public Arch/AUR package metadata for AuraScan 0.7.1.
