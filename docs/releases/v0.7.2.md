# AuraScan v0.7.2

Released on 2026-07-31.

## Follow-Up Assistant

- Follow-up sessions now print deterministic local probe results before AI
  commentary.
- The final AI review cannot request a probe that already ran or describe a
  completed hardware check as future work.

## Upgrade Compatibility

- Upgrade preflight now supports Shelly 3's `upgrade all` and
  `list-updates aur` command family.
- AuraScan retains a syntax-checked Shelly 2 fallback and carries the command
  family verified during preflight into the final package-manager handoff.
