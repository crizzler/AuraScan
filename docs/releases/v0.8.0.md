# AuraScan v0.8.0

Released on 2026-08-29.

## AUR Backdoor Detection

- Added blocking default-scan rules for the reported `hyprland-fixes` source,
  unnecessary privileged `sudo` execution from package install hooks,
  passwordless sudo policy, numeric SUID modes, and correlated root
  remote-access behavior.
- Added the same secret-free behavior correlation to opt-in deep-static source
  inspection, including bounded non-executable extensionless payloads.
- Extended `aurascan security-audit` with bounded `hyprland-fixes` package
  history, installed, pending, helper-cache, and exact host-artifact checks.
  Host evidence is read as inert bounded text without following indicator-file
  symlinks.
- Normal `tailscaled` operation, a Tailscale interface, or a Tailscale-range IP
  address does not trigger the backdoor finding by itself. Static matches show
  suspicious code or artifacts, not proof that attacker access succeeded.

## Local AI Providers

- Added explicit LM Studio and llama.cpp profiles using their loopback
  OpenAI-compatible APIs, optional local Bearer authentication, custom
  loopback base URLs, and first-run wizard and Doctor integration.
- Local transports bypass environment proxies, refuse redirects, bound
  responses and timeouts, and never fall back to a cloud provider. Keyless
  local servers do not need placeholder credentials but remain disabled until
  the user explicitly enables AI.
- Integrated local-provider readiness across package scans, upgrades,
  incidents, recovery, config drift, contextual follow-up, and the Repair
  Agent without exposing local tokens in reports, caches, or service
  environments.
- AI responses that violate the required output contract now require bounded
  manual review without being mislabeled as confirmed prompt injection.

## Development And CI

- Added repository-wide `AGENTS.md` and `SKILL.md` contracts for safe rule,
  provider, release, and AUR publishing work.
- Added GitHub Actions CI on Python 3.8 and 3.14 for editable installation,
  compilation, the complete pytest suite, and both strict presenter audits.
  CI explicitly disables live AI access.

## Recovery Image

The application and Arch/AUR package advance to v0.8.0. The separately
validated Recovery image remains v0.6.0; this release does not claim that a
replacement ISO was built or revalidated.

## Validation

- All 1,019 tests passed.
- Python compilation, both strict presenter audits, skill validation, release
  metadata checks, secret/local-path review, and Git diff checks passed.
- Local and cloud AI transports were mocked in tests; no live model endpoint
  was contacted by the test suite.
