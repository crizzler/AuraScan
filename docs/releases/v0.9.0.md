# AuraScan v0.9.0

Released on 2026-08-29.

## Agent Instruction Guard

- Added `aurascan instruction-audit`, an opt-in, unprivileged scanner for
  recognized Claude Code, shared `AGENTS.md`, and Agent Skill control files
  under a user's home directory. It performs bounded static content and
  integrity analysis without importing, rendering, sourcing, or executing a
  discovered file.
- Added correlated checks for fetch-and-execute instructions, credential
  collection plus exfiltration, automatic activation plus concealment,
  dangerous persistence, decode/eval chains, privilege abuse, dangerous hooks,
  broad tool grants, and Claude dynamic commands. Findings distinguish active
  constructs from documentation, examples, comments, and negation where
  possible and do not claim that suspicious instructions executed.
- Added first-seen review inventory, content-hash approvals bound to machine
  identity and UID, integrity-change alerts, private persistent review state,
  and fail-closed validation for corrupt, symlinked, wrongly owned, or
  permission-weakened state.
- Added confirmed, reversible disable and restore for unchanged, user-owned,
  standalone instruction files. Settings, hooks, plugin manifests, scripts,
  shared configuration, and symlinks remain manual-only; restored files return
  to unreviewed status.

## Background Monitoring And AI

- Added a disabled-by-default hardened user monitor that runs after login and
  every five minutes. It has no network access or AI credentials, treats the
  home as read-only, writes only private state, and uses bounded traversal and
  low CPU/I/O priority.
- Added a separately consented user AI assistant that processes at most one
  queued job per timer run through the configured local or cloud provider. It
  receives at most 12 KiB of redacted suspicious evidence, has no tools, and
  may raise but never lower deterministic severity or trust an integrity
  change.
- Added generic secret-free desktop alerts, persistent tray severity and a
  **Review Agent Files** action, plus CLI review state. Notifications never
  include paths, snippets, usernames, credentials, or provider text.
- Bounded private history to the current/newest 32 reports within 256 MiB and
  2,048 generic alert envelopes without treating retention as trust.
- Added setup and Doctor coverage for monitor state, scan mode, private state,
  notification readiness, separate AI consent/provider readiness, and unit
  health. All-Markdown scanning remains optional and content-only.

## Scope And Limitations

- Agent Instruction Guard uses `instruction_guard_report/1.0` and rule version
  1.0. AuraScan's existing package-scanner rule version is unchanged.
- This release provides periodic detection, not pasted-command or link
  preflight, privileged fanotify/process interception, or automatic quarantine.
  Same-UID malware can attack user files and guard state, and root malware can
  disable or deceive the monitor.
- The application and Arch/AUR package advance to v0.9.0. The separately
  validated Recovery image remains at its previously published version; this
  release does not claim a replacement ISO was built or revalidated.

## Development And CI

- Added defanged `example.invalid` fixtures and positive/negative coverage for
  discovery, parsing, bounded reads, races, integrity, private state,
  notification deduplication, AI failure isolation, disable/restore, setup,
  Doctor, tray, packaging, and CLI contracts.
- CI continues to cover Python 3.8 and 3.14 with both general and Instruction
  Guard AI disabled. Tests use temporary roots and mocked AI, systemd, tray,
  and notification interactions; they do not scan a real home or contact a
  live provider.
