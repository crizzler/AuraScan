# AuraScan v0.9.1

Released on 2026-08-30.

## Instruction Guard Tray Controls

- Added two checkable entries to the AuraScan Updater right-click menu:
  **Instruction Guard Background Scan** and **Instruction Guard AI Analysis**.
  They independently enable or disable the deterministic monitor and the
  separately consented raise-only AI assistant.
- The checkmarks refresh at tray startup and whenever the menu opens. They are
  based on the private consent configuration plus the installed user-timer
  state; unsafe, malformed, or inconsistent state fails closed and directs the
  user to AuraScan Settings or `aurascan doctor`.
- Tray changes reuse `aurascan instruction-audit` rather than duplicating
  systemd or provider logic. They run asynchronously without a shell, accept
  both clear and review-required status results, serialize mutations, and
  refresh the displayed state after every operation.

## Process And Privacy Hardening

- Bounded combined child stdout and stderr to 64 KiB, bounded each operation to
  120 seconds, and retire every completed Qt process and timeout object. A
  noisy, malformed, crashed, or stuck child fails closed without exposing its
  output.
- Desktop messages remain generic and never include paths, snippets, command
  output, usernames, credentials, or provider secrets. Enabling AI still
  requires an already configured ready local or cloud provider.
- AuraScan's tray Quit action is disabled while an enable/disable transaction
  is active so the app cannot interrupt systemd/config rollback. Status-only
  refresh work remains safely cancellable.

## Compatibility And Packaging

- Added mocked tray coverage for both Qt signal shapes, all four toggle
  directions, review-required status, drift, provider refusal, serialization,
  crash/error/timeout handling, bounded output, secret-free failures, and
  process/timer cleanup.
- Real PyQt6 and PySide6 event-loop stress tests verified bounded noisy-child
  handling and zero retained process children. The complete suite passes on
  Python 3.8 and 3.14 with AI disabled and without contacting providers or
  invoking live systemd.
- The application and Arch/AUR package advance to v0.9.1. Instruction Guard's
  report schema and rule version remain 1.0, and the package-scanner rule
  version is unchanged.
